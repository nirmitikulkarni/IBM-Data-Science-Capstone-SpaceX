# Data sources

- Standard IBM/Coursera SpaceX course dataset: `dataset_part_2.csv`; dataset not committed at this time.
- SpaceX API v4 launches: https://api.spacexdata.com/v4/launches
- SpaceX API docs: https://github.com/r-spacex/SpaceX-API
- Falcon 9 launch history: https://en.wikipedia.org/wiki/List_of_Falcon_9_and_Falcon_Heavy_launches

For reproducibility, save source URLs, retrieval time, schema and checksum when collecting files. Confirm licensing before redistributing datasets.
